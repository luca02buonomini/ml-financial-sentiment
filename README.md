# Financial Sentiment Analysis (Machine Learning project)

Classification of ~5,800 financial sentences into **positive / neutral / negative** using
TF-IDF features reduced with SVD, comparing Naive Bayes, Softmax regression, Decision Tree
and Random Forest, evaluated with stratified 5-fold cross-validation and macro-F1.
